🎨 前端

Vanilla JS ES模块
lightweight-charts (CDN)
自定义 Watchlist / Toolbar
IndexedDB 数据缓存
复用现有 base.html 导航

⚙️ 后端

Flask (现有)
新增 /chart 路由
新增 5 个数据 API
复用 TdxReader + AkshareFetcher
SSE 推送实时数据

📦 核心依赖

仅 1 个新依赖
lightweight-charts v4.x (CDN)
无 Node.js / 打包工具
无 React / Vue
全部浏览器原生能力

核心原则：在现有 Flask 项目中新增一个看盘页面和一组 API，前端用 lightweight-charts CDN + 原生 ES 模块。不引入任何构建工具或前端框架。
