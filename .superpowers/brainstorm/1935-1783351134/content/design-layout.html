📁 前端 JS 模块拆分 (8个文件)

模块文件职责
chart-core.jslightweight-charts 初始化，主图/副图创建
chart-data.jsK线数据获取、周期切换、IndexedDB缓存
chart-indicators.jsMA/MACD/RSI/布林带/成交量计算和渲染
chart-drawings.js趋势线/水平线/斐波那契/矩形等画线工具
watchlist.js自选列表管理、分组、搜索、拖拽排序
toolbar.js右侧工具面板、盘口五档渲染
strategy-overlay.js策略买卖点标注、选股结果图表联动
app.js主入口，事件总线 (Pub/Sub)，模块协调

🗄️ 后端新增 API

端点说明
GET /chart看盘页面（Jinja2模板）
GET /api/chart/kline?code=&period=多周期K线数据
GET /api/chart/intra?code=当日分时图数据
GET /api/chart/depth?code=盘口五档（实时）
GET/POST /api/watchlist自选列表 CRUD
GET /api/chart/events?code=策略事件标注（买卖点/涨停日等）
