数据源约束 — 你能拿到哪些周期的K线数据？

当前系统用通达信 .day 文件（日线），akshare 补充在线数据。多周期切换需要更细粒度数据。

A

🥇 全周期（日线+分钟线）— 推荐

日线来自通达信 .day，分钟线（5/15/30/60分钟）通过 akshare 在线拉取，前端缓存 IndexedDB。

✅ 体验最好

  • 完整多周期切换：5分 → 15分 → 30分 → 60分 → 日线 → 周线
  • akshare stock_zh_a_hist_min_em 接口支持分钟K线（近期数据免费）
  • 前端 IndexedDB 缓存，同一天内切换周期不重复请求

⚠️ 注意

  • 历史分钟数据有限（通常近1-3个月免费）
  • 每只股票首次加载需等待API响应（~1-3秒）
B

仅日线 + 分时图

K线只看日线/周线/月线，日内看分时走势图（当日）。用通达信数据，不依赖在线API。

✅ 简单可靠

  • 完全离线可用，通达信数据即可
  • 开发简单，不需要处理多周期数据转换
  • 分时图可以用 akshare 当日数据

⚠️ 限制

  • 无法看60分钟/30分钟K线——短线交易的核心需求
  • 与"TradingView 体验"差距较大
C

通达信本地分钟线（如果你有的话）

通达信 vipdoc 目录下也有 .5 文件（5分钟线）和 .1 文件（1分钟线），如果你安装了完整数据。

✅ 快速且完整

  • 本地读取，速度最快
  • 历史数据完整（取决于你的通达信数据订阅）
  • 完全离线

⚠️ 需要验证

  • 需要确认你的通达信目录下是否有 vipdoc/sz/minline/*.5 文件
  • 解析 .5/.1 文件格式与 .day 不同，需要额外开发
