# 启动突破 V3 — 对齐「逻辑哥五打法（一）」设计（2026-09-19）

## 背景

用户提供逻辑哥《核心五种打法（一）：启动突破完整教学——放量突破平台，吃一段主升》
（B站 BV11veg6fEHg，21 分钟）字幕，要求核对并更新网站「启动突破 V3」（/breakout_v3）。

视频给出的完整框架：

1. **三个前提**：① 大盘在结构性上升期（下降通道里突破"突一个死一个"）；
   ② 板块有明确催化（政策/业绩/产业 三选一，"没有催化的突破耍流氓"）；
   ③ 个股有涨停基因（股性活跃，去年到今年十次左右）。
2. **买点**：平台突破 + **放量确认**（"无量突破就是耍流氓"）；最优是**日线+周线双突破**，
   但只在行情特别好时用，一般日线级别足够；周线突破很少用在小票上（那是大票打法）。
   情绪周期上用在"冰点→修复→**发酵/高潮**"这段；**只做小票，不要做大票**。
3. **持股**：**以趋势线为底线，不破趋势不走**（黄/红/白线因股而异，两线粘合取稍远那根）；
   回落盯突破前的前期低点支撑；震荡期用**做 T** 应对（三成仓拿一半做 T，T 飞了还有底仓）。
4. **加仓**：**回踩加仓**——① 没跌破前高可接；② 回踩打到支撑可接。
5. **止损**：**跌破趋势无条件离开**；自评门槛"能不能接受回撤 8%"。
6. **仓位**：能接受回撤 8% / 有时间盯盘 / 性格果断，三条全中可重仓；中两条降到 3–4 成；
   只中一条别用。指数好→8 成，一般→3–4 成，主升配合→8 成，震荡→4 成。

**用户口径确认（2026-09-19）**：
- 范围：**全套（C）** = P0 选股/情绪/持股止损 + P1 周线双突破/催化清单/文案 + P2 加仓/做T提示；
- 小票口径：**流通市值 ≤ 100 亿硬过滤**，20–80 亿保留为加分项；
- 止损口径：**破趋势走 + -8% 绝对底线**（替换现有 -6%）；
- 取消机械移动止盈（回落>5%），改为"不破趋势不走"；
- 最长持有兜底 **5 天 → 20 交易日**。

**自动传导（无需改动，但需在验收中确认）**：
- `strategy_lab/collectors/breakout_v3.py` 与 `/api/breakout_v3/predict` 都基于
  `Vol180SimPortfolio.state['watch']`；**候选池层面的市值过滤会自动收敛它们**。

- 周线：本地日线按 W-FRI 聚合，需 ≥60 周历史，否则 `weekly_*` 置 None（不加分、不拦）。
- 情绪：`analysis/strategy_regime/live_diagnosis.get_regime_diagnosis()` 返回 `regime` + `emotion`。

## A 选股层

### A1 小票硬过滤（流通市值 ≤ 100 亿）
- 位置：`screen_candidates()` 取 `latest` 后、与 fib 纪律同级过滤：
  `float_mcap_yi > SMALL_CAP_MAX_YI(100)` → 跳过（不入选观察池）。
- 候选行带 `float_mcap_yi`；`20 ≤ 市值 ≤ 80` → 评分 **+8** 并 reasons 标"小票(20-80亿)"。
- 市值未知（无股本数据且无 spot）→ **放行**，`float_mcap_yi=None`，reasons 标"市值未知"。

### A2 周线双突破（加分 + 标记，不硬拦）
- 周线聚合：`resample('W-FRI')` 取 OHLC；`weekly_breakout` = 本周收盘 > 前 52 周最高收盘；
  `weekly_bull` = 周线 MA5 > MA10。
- `dual_breakout = weekly_breakout or weekly_bull`（与当日日线突破信号同时成立时）→ 评分 **+10**，
  候选行 `weekly_state`（'双突破'/'周线多头'/'无'），页面显示徽章。
- 缺失历史（<60 周）→ 不加分不拦。
- 同步进入 `breakout_predict` 评分（+8），使明日突破预测排名反映双突破。

### A3 情绪周期闸门
- 复用 `get_regime_diagnosis()`：
  - **禁开仓**：`regime == '退潮下跌'` 或 `emotion in ('极冰点','冰点')`
    → `_scan_buy_signals` 不生成买入信号（观察池仍展示，行标"情绪闸门：退潮/冰点禁开仓"）；
  - **最佳档**：`regime == '强势趋势'` 或 `emotion in ('活跃','火爆')` → 信号评分 +5；
  - **修复档**：`emotion in ('低迷','温和')` → 正常出信号，但评分门槛提高至 **75**；
  - 其他（弱市回调/震荡观望）→ 正常，评分门槛维持现状。
- 闸门结果写入 summary（`emotion_gate`: 状态与原因），页面顶部展示当前档位。

## B 持股/退出层（口径变更）

### B1 趋势线持股
- 新增持仓字段 `trend_line`（持股底线）与 `entry_low`（买入日最低价）：
  - 买入日初始化：`trend_line = max(entry_low, MA13)`（MA13 缺失时取 entry_low）；
  - 持仓期：若当日**收盘 > trend_line** 且当日为回踩站稳（收盘 ≥ 当日开盘），
    `trend_line = max(trend_line, 当日最低价)`（底线只升不降）。
- 卖出条件（优先级从高到低）：
  1. **收盘 < trend_line → 卖出**（主止损，"跌破趋势无条件离开"）；
  2. **亏损 ≤ -8% → 卖出**（绝对底线，替换 -6%）；
  3. 今日涨停 → 持有（连板同理）；
  4. N 字反包失败 → 卖出（保留现有逻辑）；
  5. 持有 ≥ **20 交易日** → 到期兜底卖出（原 5 天）。
- **删除机械移动止盈**（原"浮盈≥3% 后回落>5% 卖"）——与"不破趋势不走"冲突。
- 三处同步：`sim_portfolio._check_sell_v3`、`v3_backtest._check_sell_v3`、`v4_backtest._check_sell_v3`。

### B2 止损常量
- `V3_STOP_LOSS_PCT = -8.0`（替换 -6%），`V3_MAX_HOLD_DAYS = 20`。
- **注意配置来源**：现有 V3 硬止损读 `data/risk_config.json` 的 `vol180.stop_loss_pct`（默认 -6%）。
  本次需同时：① 更新代码默认值；② 迁移已存在的 `risk_config.json`（vol180.stop_loss_pct → -8）；
  ③ 页面「风控配置」显示同步。回测引擎使用自己的常量，无需读配置文件。

## C 交易操作层

### C1 回踩加仓
- 持仓中满足任一条件且**每票仅加仓一次**：
  ① **未跌破前高**：现价 ≥ 买入后最高收盘形成的颈线（`prior_high = max(买入后最高收盘)`），
     且当日收阳；
  ② **回踩站稳趋势线**：当日最低 ≤ trend_line × 1.01 且收盘 > trend_line。
- 加仓规模：单票仓位 10% → 20%（同一资金模型，`shares` 累加、成本均价重算、现金扣减）；
- 记录 `add_count`/`add_price`/`add_date`，页面显示"已加仓"。

### C2 做 T 提示（纯展示）
- 触发：持仓中 且（`regime in ('震荡观望','弱市回调')` 或 当日振幅 ≥4%）且当日未创新高；
- 页面提示："震荡期可用 1/2 仓位做T（先卖后买/先买后卖），T飞了还有底仓"；
- summary 增加 `t_tips` 字段，不做任何自动交易。

## 边界与诚实话

- **趋势线是近似**：视频用的是主图自定义线（黄/红/白），本设计用 `max(买入日低点, MA13)` 近似，
  并允许随回踩上移；不等同于视频里"因股而异"的线，故保留 20 日兜底与 -8% 底线双保险。
- **催化无法自动判定**：D1 是人工勾选 + 台账记录，不假装系统能识别政策/业绩。
- **做 T 仅提示**：不自动交易，系统无法替用户盘中执行。
- **口径变更会改变历史结果**：-6%→-8%、5 天→20 天、取消移动止盈会同时改变实盘引擎与两个回测引擎的
  历史表现；P0 落地后需重新跑一次 V3 基线（`analysis/strategy_regime/backtest_v3.py`）并更新
  `V3_STRATEGY.md` 的回测参考数字，避免文档与实现不一致。
- **不保证收益**：以上是规则对齐，不是收益承诺。
