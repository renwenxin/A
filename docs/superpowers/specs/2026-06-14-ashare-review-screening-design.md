# A股复盘+选股系统 — 设计文档

> 日期：2026-06-14 | 状态：设计已确认

## 一、项目目标

基于用户的A股短线交易体系，实现一个复盘+选股工具，核心功能：
1. 获取当日实时行情数据
2. 盘后/盘中多策略选股
3. 复盘报告生成

## 二、整体架构

```
Web 界面 (Flask + 纯HTML)
    ↓
选股引擎 (6个独立筛选器)
    ↓
数据层 (通达信.day + akshare API)
```

三个模块松耦合，数据层对上游屏蔽数据来源差异。

## 三、数据层

### 数据来源

| 数据需求 | 来源 | 说明 |
|---------|------|------|
| 历史日K线 | 通达信 `vipdoc/{sh,sz,bj}/lday/*.day` | 本地二进制文件，32字节/条记录，9,332只股票 |
| 股票名称/代码 | 通达信 .day 文件名解析 | sh600000→上海，sz000001→深圳，bj920000→北交所 |
| 当日实时行情 | akshare `stock_zh_a_spot_em()` | 实时价、涨跌幅、换手率、量比、成交额等 |
| 涨停板列表 | akshare `stock_zt_pool_em()` | 涨停时间、封单额、炸板标记、连板数 |
| 竞价数据 | akshare `stock_zh_a_auction_em()` | 集合竞价量价（1进2核心） |
| 龙虎榜 | akshare `stock_lhb_detail_em()` | 游资席位、买卖金额、机构动向 |
| 板块/概念 | akshare `stock_board_concept_*()` | 板块涨跌停数、板块强度 |
| 财务数据 | akshare `stock_financial_*()` | 流通市值、机构持股数 |

### .day 文件格式 (32字节/条)

```
offset  size  field
0       4     date (YYYYMMDD uint32)
4       4     open (分, uint32)
8       4     high (分)
12      4     low (分)
16      4     close (分)
20      4     amount (成交额, float32)
24      4     volume (成交量, 股, uint32)
28      4     reserved
```

### 数据更新策略
- 历史日线：盘后自动扫描 .day 文件增量更新
- 实时数据：盘中使用时按需拉取 akshare
- 缓存：当日数据缓存在 SQLite，避免重复请求

## 四、选股引擎

### 筛选器1：1进2筛选
**触发时机：** 收盘后（当晚选股）+ 次日 9:25-9:30（竞价确认）

**条件链：**
1. 昨日涨停（主板，非ST）
2. 流通市值 10-100亿
3. 股价 3-15元
4. 优先 10/20 个交易日内有过涨停
5. 排除龙虎榜藏獒/上塘路/东财超3家
6. 封成比 > 0.5（首板收盘后）
7. 封单额/流通市值 > 0.015
8. 10点前涨停优先
9. 60/89日均线粘合状态
10. 竞价确认：竞价量 > 昨日爆量 50%，高开符合预期

**输出：** 打分排序列表 + 竞价异动提醒

### 筛选器2：机构票筛选
**触发时机：** 每月更新一次 + 每日（底部反弹信号）

**条件：**
1. 近一年涨停次数 > 3
2. 机构持股家数 > 50
3. 非ST，非\*ST
4. 底部信号：日内涨幅 > 8% + 放量 + 板块催化

**输出：** 机构票池 + 当日底部反弹信号

### 筛选器3：龙头筛选
**触发时机：** 盘后

**条件：**
1. 近一年涨停 > 10次
2. N字结构识别（前期涨1-2板→缩量回调→反包）
3. 板块情绪风向标
4. 换手龙 > 一字龙

**输出：** 龙头列表 + N字突破信号

### 筛选器4：突破形态识别
**触发时机：** 盘后

**形态库：**
- 底部箱体突破（横盘2月+ → 放量突破上沿）
- W底（等低点 → 放量突破颈线）
- 横盘平台突破（高位横盘 → 缩量再放量）
- N字回调突破（前期龙头 → 缩量回调 → 重新放量拉起）

**复合信号：** MACD金叉 + 成交量复合炮（3炮及以上）

**输出：** 形态匹配列表 + 突破位标注 + 成交量信号

### 筛选器5：板块分歧介入
**触发时机：** 涨停潮次日

**条件：**
1. 前一日板块涨停潮（≥5只涨停）
2. 次日分歧确认
3. 龙头明牌（≥2连板）
4. 板块内无跌停、无大低开
5. 优先换手龙低吸

**输出：** 分歧信号 + 目标标的（3-5只）

### 筛选器6：竞价抢筹
**触发时机：** 9:25-9:30（实时）

**条件：**
1. 9:25 成交量 / 9:24 成交量 > 150%
2. 高开幅度匹配前日涨停时间（早盘涨停→高开>4%，下午→-2%~2%）
3. 竞价量 > 昨日爆量 50%

**输出：** 异动列表 + 抢筹强度排序

## 五、Web 界面

### 技术栈
- 后端：Flask (Python)
- 前端：纯 HTML + HTMX（无重型框架）
- 图表：pyecharts（K线、量价、热力图）

### 页面结构

1. **选股面板** `/screening`
   - 策略选择（6个筛选器可多选）
   - 一键筛选 → 结果列表
   - 支持导出Excel

2. **复盘报告** `/review`
   - 当日涨停复盘（涨停股、炸板率、涨停时间分布）
   - 板块强度排行
   - 龙虎榜速览
   - 连板高度统计

3. **个股详情** `/stock/<code>`
   - K线图（叠加 60/89/250 日均线）
   - 成交量柱 + 复合炮标注
   - 形态识别标注
   - 基本信息（市值、板块、涨停历史）
