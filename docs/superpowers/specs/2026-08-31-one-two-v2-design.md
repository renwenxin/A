# 1进2 精选优化（今日1进2 · 视频方法论版） 设计文档

日期：2026-08-31
状态：已获用户逐节确认（brainstorming 流程）

## 1. 背景与目标

用户学习了 C:\Users\15195\Desktop\视频 中逻辑哥的 1进2 教学视频（《全网最全1进2讲解》《涨停接力实战手册》《竞价擒牛》《集合竞价秘密》《情绪周期理论》等），要求：按视频方法论优化 1进2 精选选股，成品放在**交易流程**（新页面），**不动复盘分析**，并**每天用实盘结果反哺优化**。

视频核心方法论提炼（可量化信号）：
- 竞价爆量战法：竞价成交额/自由市值 ≥10% 涨停概率极大、≥5% 约70%、≥3% 较高
- 图形突破：二板跳空高开过左侧压力位（压力越多越好）→ 压力变支撑
- 超预期/弱转强：昨日烂板/尾盘封板 → 今日早盘快速转强冲板
- 合理量能：二板量达前高量 80% 左右最佳；极致缩量/爆量都不好
- 情绪周期：二连冰日做 1进2 胜率高、二连高潮次日胜率低
- 高能量梯队：一字板最多的板位 = 资金进攻方向（决定做 1进2 还是 2进3）
- 个股地位：上方无同题材高位 → 补涨龙机会；有 → 后排套利
- 题材叠加：关联概念越多越好（万金油）
- 市值票值：市值小 + 股价低（轿子轻）
- 卖出纪律：全天成交额/封板时成交额<1.3、竞价量>昨日最高量50%、挂卖五防炸板

## 3. 数据模型

**权重配置 `data/one_two_weights.json`**（页面可调，原子写，损坏回退默认）：
- dimensions：quality 30 / theme_stage 15 / emotion 10 / energy_ladder 10 / volume_health 15 / theme_overlay 8 / cap_price 7 / status 5
- thresholds：auction_ratio_high 10.0 / auction_ratio_mid 5.0 / auction_ratio_low 3.0 / volume_health_pct 80.0 / cap_max 100.0 / price_max 15.0

**结果台账 SQLite `data/one_two_ledger.db`** 单表：
- pick_date/code/name/score/dimensions(JSON)/tactic('auction'|'graph'|'weak_strong')
- next_date/next_result('zt'|'up3'|'up'|'flat'|'down')/hit(1/0/NULL)/auction_ratio
- 唯一约束 (pick_date, code)

## 4. 盘后精选打分（8 维）

输入：今日涨停池 + TDX 日线 + 情绪周期（market_state）+ 概念映射。只收首板（连板=1），排除一字板/ST/北交所。Top N（默认 8）输出，含维度明细与战法标签。

| 维度 | 规则 | 默认分 |
|---|---|---|
| quality | 早盘封板≤10:30 +10 / 封成比>0.5 +10 / 封单强度>0.015 +6 / 封死未炸 +4；晚封扣分 | 30 |
| theme_stage | 试水期 +15 / 兑现期 -10 / 朦胧期 -5 | 15 |
| emotion | 二连冰日 +10 / 高潮次日 -8 | 10 |
| energy_ladder | 2 板梯队是主攻 +10 / 资金攻 3 板 -5 | 10 |
| volume_health | 二板量/前高量 0.7~1.0 +15 / <0.4 或 >1.5 -8 | 15 |
| theme_overlay | 概念≥3 +8 / 1-2 +4 / 0 -2 | 8 |
| cap_price | 市值≤50 亿且价≤15 元 +7 / 单一 +4 / 市值>100 -5 | 7 |
| status | 上方无同题材高位 +5 / 有 -3 | 5 |

战法分类（三选一）：
- graph：首板未过前高、近 60 日有左侧压力位（二板可跳空）
- weak_strong：烂板/尾盘封板（封板>14:00 或炸板回封）
- auction：其余（竞价公式次日确认）

## 5. 次日竞价确认（9:25 后）

- 爆量比 = 竞价成交额/自由市值×100：≥10% 极强(🔴) / ≥5% 高(🟠) / ≥3% 较高(🟡) / <3% 平淡(⚪)
- 竞价涨幅 >1% 才入池；战法联动：
  - graph：竞价跳空高开过左侧压力位 → 触发"图形突破买点"
  - weak_strong：高开≥3% 且竞价量>昨日最高量50% → 触发"弱转强买点"
- 无竞价数据降级"待 9:25 后刷新"，不阻塞盘后展示

## 6. 台账与优化闭环

- 每日盘后精选自动落库；次日验证（TDX + 涨停池）→ next_result/hit/auction_ratio
- 维度命中率：各维度"得正分 vs 非正分"标的命中率对比（验证该维度有效性）
- 按战法 / 按情绪阶段命中率
- 权重+阈值页面可调 → 次日盘后选股生效

## 7. 页面与接线

导航：交易流程加「🧩 今日1进2」（多策略选股与竞价分析之间）。

页面 /one_two_picks 四区块：
1. 📋 今日精选（盘后榜单 + ⚡盘后精选按钮）
