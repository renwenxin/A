# 首页全功能总览（Workbench 升级） 设计文档

日期：2026-08-16
状态：已获用户逐节确认（brainstorming 流程）

## 1. 背景与目标

首页（工作台）目前只列出 10 个功能入口，三个新功能（消息雷达/预测台账/策略验证台）与 V1/V2 选股页、个股分析没有入口。目标：首页升级为**全功能总览**——16 个功能全部有卡片入口与说明，4 个数据型功能附带轻量实时状态徽标，让首页成为"状态面板 + 入口地图"。

## 2. 范围（用户已确认）

| 决策点 | 选择 |
|---|---|
| 范围 | A：16 个入口全部纳入分组（补 V1/V2/雷达/台账/验证台/个股分析） |
| 形态 | B：入口卡 + 4 个数据型功能状态徽标 |
| 分组 | 盘前准备 / 盘中交易 / 盘后复盘 / 数据与研究 |
| 个股分析 | 通用入口文案（点击进示例页） |

## 3. 分组与卡片

| 分组 | 卡片 |
|---|---|
| 盘前准备 · 9:15 前 | 多策略选股 / 启动突破 V3 / V2 选股池 / V1 启动突破 / 竞价四维分析 |

新增 6 张卡片文案（沿用 .home-card 风格）：
- V2 选股池 → /breakout_v2（V2 状态机选股池：仓位分配/观察→就绪→持仓流转）
- V1 启动突破 → /breakout（经典突破筛选）
- 消息雷达 → /event_radar（事件→产业→公司→资金→股价，12 预置主题）
- 预测台账 → /prediction_ledger（三类预测次日验证与准确率）
- 策略验证台 → /strategy_bench（5 战法统一回测 + 绩效对比）
- 个股深度分析 → /stock/000001（通用文案）

原有 10 张卡片文案保留不动（仅分组微调）。

## 4. 状态徽标（4 个数据型功能）

首页并行请求 4 个轻量 API，卡片右下角显示徽标；失败/空数据隐藏，不阻塞渲染：

| 功能 | 数据源 | 徽标 |
|---|---|---|
| 预测台账 | GET /api/ledger/summary（**新增**） | 精选命中率 xx% · 周期 xx% |
| 策略验证台 | GET /api/strategy_bench/snapshots（已有） | 最近快照 HH:mm · 年化 xx% |
| 消息雷达 | GET /api/radar/results（已有） | 今日结果 N 主题 / 待分析 |
| 模拟持仓 | GET /api/risk/status?portfolio=vol180（已有） | 持仓 N 只 · ⛔熔断/✅可开仓 |

实现：新增 `GET /api/ledger/summary`（返回 `LedgerStore().summary(30)` JSON）；卡片内 `<span class="hc-badge" id="badge-*">`；页面底部 JS 用 `Promise.all` + `textContent`（无 XSS）填充；`style.css` 加 `.hc-badge` 样式。
