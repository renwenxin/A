④ 方法与风险
第 0 步 · 先定问题：把"能不能做"拆成两个独立问题 —— (a) 历史上这种广度状态下，这套战法赚不赚钱？（分组统计） (b) 这个结论稳不稳？（四条稳健性轴） (a) 好看但 (b) 不稳，一律不给结论。
第 1 步 · 归组（单轴）：取回测逐笔表，按 signal_date → 当天广度状态 分桶（不是按买入日，因为信号在收盘、买入在次日开盘）。 只用广度口径这一个轴：涨停/跌停家数 + 炸板率 + 最高连板 + 指数 vs MA20 → 强势主升/强势震荡/弱势震荡/情绪退潮/冰点/极端行情。
第 2 步 · 算四个数：交易笔数 n、胜率、笔均收益、盈亏比。笔均 = 期望，胜率 = 稳定性，盈亏比 = 靠什么赚钱。
第 3 步 · 四条稳健性轴（关键，也是我和"看回测数字就下结论"的区别）：
· 跨版本：同一批交易用 {{ d.n_variants }} 个不同版本的回测结果各算一遍 → 方向一致才算数。
· 跨阈值：把炸板率阈值在 35/40/45 移动 → 看笔均是否翻号（阈值型状态对参数敏感）。
· 跨时点口径：广度状态有两种挂法 —— 斩龙的「T-1 广度」和「T 日收盘广度」；两种都合法、都在买入前可得，符号相反就说明这一格本身不稳。
· 跨口径：把同一格成交按本工程 regime 再分桶、取子桶笔均的 n 加权平均，与广度口径笔均比符号。 本工程 regime 口径只在这一步出现，它不产生自己的灯。
· 任一轴明确翻转 → 判「🟣 不稳」；某轴样本不足（None）不算翻转，不改变结论。
第 4 步 · 灯由固定规则生成，不让我主观介入（顺序即优先级，第一条命中为止）：
① 无样本 / n<15 → ⚪ 样本不足； ② 跨版本方向不一致 → 🟣 不稳； ③ 跨时点口径符号相反 → 🟣 不稳； ④ 跨阈值符号翻转 → 🟣 不稳； ⑤ 跨口径符号相反 → 🟣 不稳； ⑥ 笔均 ≤0 → 🔴 停用（n≥30）否则 ⚪ 样本不足； ⑦ 胜率≥50% 且 n≥30 → 🟢 首选； ⑧ 胜率≥45% → 🔵 可用； ⑨ 其余（正期望、胜率<45%）→ 🟡 谨慎（靠盈亏比，必须降仓 + 快进快出）。
阈值写在 ashare_review/analysis/strategy_fit.py 顶部常量，可自行调整。
第 5 步 · 本工程 regime 怎么用：它不并排、不给第二套结论。 它只在第 ③ 节作为证据出现：与广度口径同向 → 不改变结论；反向 → 该格判「不稳」。 这样"分歧"不再是一个需要人来权衡的结论，而是一个会直接让格子变灰的校验位。
第 6 步 · 口径风险自查（写在这里，避免被数字误导）： · 我的广度是 TDX 自算（涨停家数系统性高约 6 家、炸板率偏高），与斩龙用的东财口径不完全可比 → 阈值型状态会漂； · 回测只有 {{ d.window }} 一个市场结构、部分状态几十笔，「冰点」0 天； · 成本按 0.35%/笔、逐笔等权，实盘摩擦只会更差。
第 7 步 · 明确不做什么： 不用这些数字预测涨跌；不因为某一格历史数字漂亮就改阈值（那是拟合）；不把"历史上正期望"当成"下次会赚"； 不挑一个好看的时点口径/统计口径单独拿来说事。
