🌅 一、每日开盘前检查清单（9:00-9:25）
  • 9:00 大盘 MA20 状态确认
    打开上证指数日线图，确认昨日收盘价与 MA20 的关系：
      ✅ 收盘 > MA20 → 允许开仓，进入下一步
      ❌ 收盘 ≤ MA20 → 今日禁止新开仓，仅管理现有持仓
  • 9:10 检查现有持仓触发状态
    遍历所有持仓，按优先级检查：
      🔴 浮亏 ≥ 6% → 今日开盘立即挂单卖出（硬止损）
      🟠 非涨停买入 & 从最高点回落 ≥ 3% → 挂单卖出（移动止盈）
      🟣 涨停买入 & 昨日断板 & 今日为断板后第2天未反包 → 挂单卖出
      🟢 涨停买入 & 昨日首次断板 → 观察一天（等N字反包）
  • 9:15 熔断状态检查
    检查当前连续亏损笔数：
      📊 连亏 0-2 笔 → 正常，仓位 = 10%/票
      ⚠️ 连亏 3-4 笔 → 仓位减半至 5%/票
      🚫 连亏 ≥ 5 笔 → 强制空仓 2个交易日，今日不开新仓
      ✅ 出现一笔盈利 → 连亏计数归零，仓位恢复 10%
  • 9:20 集合竞价扫描
    检查昨日信号池中候选标的的竞价情况：
      ❌ 低开 > 3% → 放弃该标的
      ❌ 竞价量 < 前日量 × 50% → 放弃该标的
      ❌ 开盘跌停 → 放弃该标的
      ✅ 全部通过 → 列入今日可买入清单
  • 9:25 确定买入计划
    从通过竞价确认的标的中，按评分排序，选取前 3 只：
      📌 单票仓位 = 当前熔断级别仓位（10% 或 5%）
      📌 总持仓 ≤ 10 只
      📌 记录 买入日是否涨停 → 决定后续退出模式
  • 开盘前 核对回测基线
    刷新系统面板，确认：
      📈 当前净值 vs 回测同期净值（允许 ±15% 偏差）
      📉 当前回撤 vs 回测最大回撤 17.5%
      📊 当前胜率 vs 回测胜率 50.6%

🚨 四、异常情况应对流程

场景 1：连续亏损触发熔断后的恢复流程

[CB] 5 consecutive losses → FORCE 2 DAYS EMPTY Day 1 (空仓): 不进行任何买入操作，仅管理现有持仓的退出 Day 2 (空仓): 同上，等待强制空仓期结束 Day 3 (恢复): 1. 连亏计数归零 → 仓位恢复至 10% 2. 检查 SH > MA20 → 如满足，按正常流程筛选候选标的 3. 每日最多开仓 3 只（非补仓——熔断恢复后从零开始） 4. 不要试图"追回亏损"——遵守标准仓位规则 ⚠ 如果恢复后第1笔交易再次亏损 → 连亏计数=1，但仓位仍为10% ⚠ 如果恢复后3笔内再次触发熔断 → 考虑暂停本周交易（市场环境可能极端不利）

场景 2：实盘净值显著偏离回测基线

偏离阈值：累计收益偏差 > 15%、或最大回撤偏差 > 5pp、或胜率偏差 > 10pp。

[ALERT] 实盘净值偏离回测基线超过阈值 调查步骤： Step 1: 检查过去1周内是否有单日出现 3+ 笔同时亏损 → 若有：大盘可能处于突发利空/系统性下跌，回顾当日 MA20 是否已破位 Step 2: 检查是否有标的买入后未按退出规则执行（手动干预导致） → 若有：统计手动干预 vs 规则执行的收益差异 Step 3: 检查滑点是否显著高于 0.05%（实盘买入价 vs 信号价） → 若有：暂停流动性差的标的，优先做日均成交 > 2亿的票 Step 4: 检查最近一周胜率是否低于 35%（回测均值的 -15pp） → 若是：考虑将仓位降至 5%，等待胜率回归均值 Step 5: 若以上排查无果且偏离持续 > 5天 → 暂停策略，人工复盘全部交易

📖 六、V4 策略规则完整参考
🟢 开仓条件
  • 上证收盘 > MA20
  • 沪深主板，非ST
  • 年涨停 ≥ 10次
  • 距找顶线 ≤ 10%
  • 收盘突破找顶线
  • 量 > MAVOL180 × 1.2
  • 量比 < 5.0x（非过度放量）
  • 距压力位不在 3-5%（非死亡区间）
  • 竞价：低开≤3%、缩量≤50%、非跌停
🔴 退出层级（优先级从高到低）
  • 1. -6% 硬止损（无条件）
  • 2. 涨停日买入：涨停→持有；断板→等N字反包1天→收阳放量=持有，否则=卖出
  • 3. 非涨停日买入：浮盈≥2%后，从最高价回落≥3%→卖出
  • 4. 今日涨停：继续持有
  • 5. 持有5天：到期卖出
⚡ 仓位熔断
  • 正常：单票 10%
  • 最大持仓：10只
  • 每日最多新开：3只
  • 连亏3-4笔：仓位减半至5%
  • 连亏≥5笔：强制空仓2天
  • 出现1笔盈利：计数归零，恢复10%
🟡 过滤规则
  • 死亡区间 3-5%：跳过
  • 过度放量 ≥ 5x：跳过
  • 非一字板：跳过
  • 次日开盘跌停：跳过
  • 开盘低开 > 3%：跳过
  • 竞价缩量 > 50%：跳过
