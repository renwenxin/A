# MAVOL180 量价突破战法 — 策略文档

## 一、策略概述

**策略类型**：短线突破追涨（持有 1-5 天）

**核心思想**：当个股价格突破 zigzag 找顶线（关键技术压力位），同时成交量突破 MAVOL180（180日均量 × 1.2），说明主力资金用真金白银推过关键阻力位。次日开盘买入，连板持有，断板卖出。

**回测来源**：2025-05 至 2026-07，约 290 个交易日，721 笔完成交易。

---

## 二、选股条件（4 个硬性门槛）

| # | 条件 | 参数 | 逻辑 |
|---|------|------|------|
| 1 | **沪深主板** | 60/00/001/002 开头 | 排除创业板、科创板、北交所 |
| 2 | **近一年涨停 > 10 次** | ≥ 9.5% 涨停阈值 | 股性活跃，有主力资金反复操作 |
| 3 | **非 ST/非 *ST** | 名称不含 ST | 排除垃圾股 |
| 4 | **距 zigzag 找顶线 ≤ 10%** | 前一日收盘在找顶线下方 0-10% | 即将突破但尚未突破 |

### zigzag 找顶线

用通达信主图指标 `找顶线` 的完整算法（11 日窗口确认 swing high → 三层 zigzag 过滤 → 最近 2 个 NN 波峰连线并线性外推），识别最近的技术压力位。

---

## 三、买入信号（3 个硬性条件，全部必须满足）

| # | 条件 | 参数 | 说明 |
|---|------|------|------|
| 1 | **价格突破** | 收盘价 > 找顶线 | 当日收盘站上压力位 |
| 2 | **成交量突破** | 当日量 > MAVOL180（= 180 日均量 × 1.2） | 显著放量确认 |
| 3 | **真突破验证** | 前一日收盘在找顶线下方 0-10% | 防止假突破 |

**买入时机**：信号日（T 日）的次日开盘价买入。

**买入保护**：
- 开盘涨停（≥ 信号价 × 1.095）→ 放弃（买不到）
- 高开超 5%（> 信号价 × 1.05）→ 放弃（追高风险）

## 五、卖出规则（两种模式）

### 5.1 原始模式

```
买入后逐日检查：
  ├─ 当日涨停 → 继续持有
  ├─ 曾经涨停但现在不涨停了（断板）→ 当日收盘卖出
  └─ 持有满 3 天从未涨停 → 第 3 天收盘卖出
```

### 5.2 增强模式（含 -6% 止损）

```
在原始模式基础上增加：
  └─ 当日收盘价相对买入价跌幅 ≥ 6% → 当日收盘立即卖出
```

**两种模式回测对比**：

| 指标 | 原始 | 含 -6% 止损 |
|------|:----:|:-----------:|
| 胜率 | 51.5% | 49.8% |
| 平均收益 | +2.98% | +2.91% |
| 累计收益 | +2,147% | +2,099% |
| 盈亏比 | 1.85 | 1.97 |
| 最大单笔亏损 | -26.38% | -18.16% |
| 连板交易 | 185 笔（91.4% 胜率） | 168 笔（96.4% 胜率） |

## 八、已知局限

1. **信息维度瓶颈**：31 个因子本质只有 4 类信息（价格、成交量、市场状态、历史股性），技术面已挖掘完毕
2. **无法预测连板**：连板 vs 非连板在信号层面几乎无区分（评分、涨幅、量比均无差异）
3. **止损误杀**：-6% 止损拦截了 188 笔亏损，但也误杀了 17 笔会连板大涨的交易
4. **样本时间跨度**：仅 2025-2026，跨年回测管线尚未打通
5. **无分钟级/Level2 数据**：缺少封板时间、炸板次数、排单速度等盘口信息

## 九、推荐实盘参数

| 参数 | 推荐值 |
|------|:------:|
| 选股范围 | 沪深主板（60/00/001/002） |

| 距压力位 | 0%-10%（避开 3-5% 死亡区间） |
| 量比 | > 1.0 倍 MAVOL180（避开 ≥ 5x 过度放量） |

| 高开保护 | 不超过信号价 × 1.05 |
| 止损 | 收盘跌破买入价 -6% |
| 止盈/持有 | 连板则持有至断板 |
| 最大持有 | 3 天（无涨停则到期卖出） |
| 每笔仓位 | 等权重（≤ 总资金 10%） |
| 最大持仓 | ≤ 8 只 |
