# 启动突破 V3 — 完整策略文档

> **版本**: V3.0  
> **战法名称**: VOL180 量价突破 + Zigzag 找顶线突破（竞价确认 + N字反包 + 移动止盈）  
> **更新时间**: 2026-07-23  
> **平台**: 本地 TDX 数据 + Flask Web 面板  
> **前置版本**: [V2_STRATEGY.md](V2_STRATEGY.md)

## 一、策略概述

启动突破 V3 在 V2 的基础上，根据策略评估报告的三个关键缺口，新增了四项核心改进：

| 改进 | 内容 | 解决的问题 |
|------|------|-----------|
| 🟢 **竞价确认** | T+1 买入前复查：低开>3%放弃 / 缩量>50%放弃 | V2 的"次日开盘直接买"不检查竞价质量 |
| 🟣 **N 字反包** | 涨停后断板不立即卖，等一天看放量反包 | V2 断板卖出会把 N 字第二波洗出去 |
| 🟠 **移动止盈** | 从持仓最高价回落 > 5% 才卖，最长持有 5 天 | V2 机械的"满 3 天清仓"容易错过主升浪 |
| 🔵 **板块共振** | 同板块 ≥ 3 只突破信号 → 评分 +15 | V2 只看个股技术面，不看板块效应 |

保留 V2 所有核心机制：-6% 硬止损、死亡区间过滤（3-5%）、过度放量过滤（≥5x）。

## 三、买入信号

### 3.1 核心触发条件（与 V2 相同）

```
条件 A: 收盘价 > Zigzag 找顶线（压力位）
条件 B: 当日成交量 > MAVOL180 × 1.2
```

### 3.2 V3 买入流程（新增竞价确认环节）

```
T 日收盘:
  检测到突破信号 → 进入 READY 状态 → 标记 mode='v3'

T+1 开盘前（竞价确认）:
  ├─ 低开 > 3% → 🔴 放弃买入（"竞价低开-X%"）
  ├─ 当日量 < 前日量 × 50% → 🔴 放弃买入（"竞价缩量>50%"）
  ├─ 开盘跌停 → 🔴 放弃买入（"开盘跌停"）
  └─ 全部通过 → 🟢 开盘买入

买入价: T+1 开盘价（模拟）/ 可手动修改
```

### 3.3 买入评分体系（满分约 110 + V3 板块共振）

```
基础分: 20

距离质量:  距≤3%→+25 / ≤5%→+20 / ≤10%→+15
量能突破:  量比≥3.0x→+20 / ≥2.0x→+15 / ≥1.5x→+10 / ≥1.0x→+5
均线状态:  MA5>MA10→+8 / 收盘>MA5→+5
当日涨幅:  涨停→+12 / 大阳(≥7%)→+6 / 其他→+2
板块共振:  同板块≥3只→+15   ← 🆕 V3 新增
```

## 四、卖出纪律

### 4.1 V3 自动卖出规则（四级优先级）

| 优先级 | 触发条件 | 动作 | 卖出价 |
|--------|----------|------|--------|
| 🔴 最高 | **收盘价 ≤ 买入价 × 0.94**（亏损 ≥ 6%） | 立即止损 | 当日收盘价 |
| 🟣 高 | **移动止盈**：从最高价回落 > 5%（需先浮盈 ≥ 3%） | 锁利卖出 | 当日收盘价 |
| 🟠 中 | **N 字反包失败**：涨停→断板→次日未放量收阳 | 确认卖出 | 次日收盘价 |
| 🟢 低 | **持有 ≥ 5 天兜底**（始终没涨停） | 到期卖出 | 第 5 日收盘价 |
| 🔵 — | **今日涨停** → 继续持有 | 不卖 | — |

### 4.2 V3 卖出规则详解

**移动止盈（替代 V2 的"满 3 天到期"）：**
```
持仓期间持续跟踪 highest_close（买入以来最高收盘价）
当 (当前价 - highest_close) / highest_close ≤ -5% → 卖出
保护：浮盈 ≥ 3% 后才启用（避免刚买入就被震出去）
最长持有：5 天兜底（比 V2 的 3 天更宽松，给趋势空间）
```

**N 字反包（优化 V2 的"断板卖出"）：**
```
Day 1: 持仓涨停 → had_zt = True，继续持有
Day 2: 断板（不涨停）→ 不立即卖！设置 awaiting_reversal = True
Day 3: 检查反包 ─┬─ 收阳 + 放量 → N字反包成功！清除标志，继续持有
                 └─ 继续下跌/缩量 → 反包失败，卖出（"断板反包失败"）
```

## 五、仓位管理（与 V2 相同）

### 5.1 三三四体系

| 层次 | 占比 | 用途 |
|------|------|------|
| 底仓 | 30% | 竞价确认后建仓 |
| 加仓 | 30% | 回踩均线不破 / 走强时加 |
| 子弹 | 40% | 应对炸板低吸 / 尾盘确认 |

### 5.2 单票限制

| 资金规模 | 持仓数 | 单票上限 |
|----------|--------|----------|
| ≤ 10 万 | 1-2 只 | ≤ 70% |
| 10-50 万 | 2-3 只 | ≤ 35% |
| 50 万+ | 2-4 只 | ≤ 25% |

### 5.3 总仓位 × 行情矩阵

| 市场状态 | 总仓位 | 单票上限 |
|----------|--------|----------|
| 放量上涨 + 主线明确 | ≤ 70% | ≤ 30% |
| 缩量震荡 + 板块轮动 | ≤ 40% | ≤ 20% |
| 缩量阴跌 + 无主线 | ≤ 20% | ≤ 10% |
| 急跌恐慌 | 30% 后手 | ≤ 15% |

### 5.4 连亏应对

| 连亏次数 | 应对 |
|----------|------|
| 2 笔 | 仓位降到 50% |
| 3 笔 | **当天停止交易，空仓 2 天**，重新从 50% 开始 |

## 六、市场环境匹配

### 6.1 大盘 × 个股矩阵

| 大盘趋势 | 个股状态 | 操作级别 | 策略 |
|----------|----------|----------|------|
| 上升趋势 | 放量突破 | **S-1 重仓出击** | 正常仓位 |
| 上升趋势 | 缩量回调 | A-2 回踩加仓 | 等确认信号 |
| 横盘震荡 | 放量突破 | A-1/A-3 中等仓位 | 降低仓位 |
| 下降趋势 | 放量突破 | 轻仓试错/放弃 | ≤ 20% 或空仓 |
| 下降趋势 | 其他 | **空仓** | 不参与 |

### 6.2 题材生命周期

| 阶段 | 特征 | 策略 |
|------|------|------|
| 萌芽期 | 首板零星出现 | 观察，首板试错 |
| 发酵期 | 连板出现，板块扩散 | **重仓出击**（最肥美阶段） |
| 高潮期 | 龙头加速，跟风补涨 | 持筹为主，去弱留强 |
| 退潮期 | 龙头断板，炸板潮 | **清仓，管住手** |
| 冰点期 | 涨停 ≤ 20，连板高度压到 2 板 | 做功课备选，等下一周期 |

## 七、V3 状态机

```
WATCH (观察池)
  │
  │ 收盘突破找顶线 + 量>MAVOL180×1.2 + 板块共振评分
  ▼
READY (待买入)
  │
  │ T+1 竞价确认（低开>3%? 缩量>50%? 跌停?）
  ├─ 通过 → HOLDING
  └─ 不通过 → FINISHED (skipped)
  ▼
HOLDING (持仓中)
  │  跟踪 highest_close、had_zt、awaiting_reversal
  │
  │ 涨停 → 继续持有
  │ 断板 → 等一天看 N 字反包
  │ 回落 > 5% → 移动止盈
  │ 亏 > 6% → 硬止损
  │ 持有 ≥ 5 天 → 到期
  ▼
FINISHED (已完成)
```

### 7.1 V3 持仓新增字段

| 字段 | 类型 | 说明 |
|------|------|------|
| `highest_close` | float | 买入以来最高收盘价（移动止盈基准） |
| `trailing_drop_pct` | float | 当前价距最高价回落百分比 |
| `awaiting_reversal` | bool | 是否在等待 N 字反包（断板后第一天） |
| `reversal_day_close` | float | 断板日收盘价（用于次日反包判断） |
| `reversal_day_vol` | int | 断板日成交量（用于次日放量判断） |

### 10.4 每日操作流程

```
15:00 收盘后:
  1. 打开 http://127.0.0.1:5000/breakout_v3
  2. 点击 🔍「运行扫描」 → 等待候选池重建（首次约 3-5 分钟）
  3. 查看 🟢「明日开盘买入」→ 记录计划买入的标的

  6. 点击 🔄「刷新状态」 → 系统自动执行竞价确认

```
