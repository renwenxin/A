> **版本**: V2.0 (Frozen)  
> **战法名称**: VOL180 量价突破 + Zigzag 找顶线突破  
> **更新时间**: 2026-07-23  
> **平台**: 本地 TDX 数据 + Flask Web 面板 + 聚宽 JoinQuant

## 一、策略概述

启动突破 V2 是一个基于 **Zigzag 找顶线压力位** 和 **MAVOL180 成交量** 的 A 股短线突破战法。核心逻辑：找到被 zigzag 算法确认的压力位（找顶线），在股价距压力位 ≤10% 时进入观察，等待某一天**收盘价突破找顶线 + 成交量突破 MAVOL180 × 1.2** 同时发生时，次日开盘买入。

V2 相比 V1 新增三个关键改进（基于回测数据验证）：

| 改进 | 内容 | 回测依据 |
|------|------|----------|
| 🔴 -6% 硬止损 | 收盘价跌破买入价 -6% → 立即卖出 | 止损拦截 188 笔（均 -8.95%），<-10% 极端亏损从 77 → 52 笔（-32%） |
| 🟡 死亡区间过滤 | 距压力位 3-5% 的突破信号 → 跳过 | 该区间连板率最低 |
| 🟠 过度放量过滤 | 量比 ≥ 5x → 跳过 | 大亏率 37.5% |

| # | 条件 | 参数 | 说明 |
|---|------|------|------|
| 1 | 板块 | 沪深主板 | 60xxxx / 00xxxx / 001xxx / 002xxx，排除科创板(688)、创业板(300/301)、北交所(8/4) |
| 2 | 非 ST | 名称不含 ST/\*ST | `_is_stock_st()` 检查 |
| 3 | 年涨停次数 | **> 10 次**（主板） | 快速数涨停法：读二进制日线，`chg ≥ 9.3%` 计数，回溯 250 个交易日 |
| 4 | 距找顶线 | **0% < 距找顶线 ≤ 10%** | 股价在找顶线**下方**，且距离不超过 10%（已突破的不算"即将突破"） |
| 5 | 实盘二次校验 | 近 2 日收盘 < 前 20 日最高点 × 1.015 | 排除已提前突破（找顶线在强势股中易虚高） |

### 2.2 加分项（影响评分，不影响入选）

| # | 条件 | 加分 | 说明 |
|---|------|------|------|
| 1 | 创 250 日新高 | +20 | 距 250 日高点 ≥ 0% → 主升浪 |
| 2 | 距 250 日高 ≤ 3% | +10 | 突破在即 |
| 3 | 操盘线控盘（SWL > SWS） | +20 | 主图操盘线确认控盘 |
| 4 | 操盘线即将控盘 | +10 | SWL 与 SWS 差值 < 2% |
| 5 | 均线粘合（60/89 日） | 观察 | 蓄势充分信号 |
| 6 | 板块有联动效应 | 观察 | 同板块多只标的共振 |

### 2.3 V2 过滤规则（直接排除）

| 过滤规则 | 条件 | 原因 |
|----------|------|------|
| 死亡区间 | 3% < 距压力位 ≤ 5% | 该区间连板率最低，突破后表现差 |
| 过度放量 | 量比 ≥ 5.0x | 大亏率 37.5%，主力出货嫌疑 |
| 非一字板 | 开盘 ≥ 收盘 × 1.095 | 一字板买不到，跳过 |

## 三、买入信号

### 3.1 核心触发条件（两个必须同时满足）

```
条件 A: 收盘价 > Zigzag 找顶线（压力位）
条件 B: 当日成交量 > MAVOL180 × 1.2
```

其中 `MAVOL180 = MA(volume, 180) × 1.2`，即 180 日均量的 1.2 倍。

### 3.2 额外硬性要求

- **前一日收盘价在找顶线下方**（真突破确认）
- **前一日距找顶线 0~10%**（蓄势区间）
- **非一字板**（开盘价 < 收盘价 × 1.095）
- **次日开盘不跌停**（开盘价 > 前日收盘 × (1 - 涨跌幅阈值)）

### 3.3 买入执行

| 步骤 | 说明 |
|------|------|
| 信号日 | T 日收盘后检测到突破信号 |
| 买入日 | T+1 日（下一交易日）开盘买入 |
| 买入价 | 次日开盘价（模拟）/ 可手动输入实际买入价 |
| 保护 | 开盘涨停（≥9.5%）→ 不追；开盘跌停 → 跳过该笔 |

### 3.4 买入评分体系（满分约 110）

```
基础分: 20

距离质量 (前一日距找顶线距离):
  距 ≤ 3%   → +25  紧贴压力位，蓄势充分
  距 ≤ 5%   → +20
  距 ≤ 10%  → +15

量能突破 MAVOL180:
  量比 ≥ 3.0x → +20  爆量突破
  量比 ≥ 2.0x → +15  显著放量
  量比 ≥ 1.5x → +10  放量
  量比 ≥ 1.0x → +5   达标

均线状态:
  MA5 > MA10 → +8   多头排列
  收盘 > MA5 → +5   站上MA5

当日涨幅:
  涨停(≥9.5%)  → +12
  大阳(≥7%)    → +6
  其他         → +2
```

## 四、卖出纪律

### 4.1 自动卖出规则（系统强制执行）

| 优先级 | 触发条件 | 动作 | 卖出价 |
|--------|----------|------|--------|
| 🔴 最高 | **收盘价 ≤ 买入价 × 0.94**（亏损 ≥ 6%） | 立即止损 | 当日收盘价 |
| 🟡 高 | **之前涨停过 + 今日断板**（涨幅 < 涨停阈值） | 断板卖出 | 当日收盘价 |
| 🟢 中 | **始终没涨停 + 持有 ≥ 3 天** | 到期卖出 | 第 3 日收盘价 |
| 🔵 低 | **今日涨停** → 继续持有，标记 `had_zt = True` | 不卖 | — |

### 4.2 涨停阈值

| 板块 | 涨停阈值 |
|------|----------|
| 主板（60/00/001/002） | 9.5% |
| 创业板（300/301） | 19.9% |
| 科创板（688） | 19.9% |
| 北交所（8/4） | 29.9% |

### 4.3 人工卖出参考（盘感辅助）

- **竞价不及预期** → 竞价直接核按钮，不等修复
- **分时白线破均价线不收回** → 减仓/出清
- **涨停开板放大量** → 减仓（资金出逃信号）
- **持续在均线下方 > 15 分钟** → 放弃
- **尾盘不封板** → 全部出清
- **冲高 7%+ 没封板** → 先卖锁利
- **冲高到 7%+ 被砸到平盘** → 清仓

## 五、仓位管理

### 5.1 三三四体系

| 层次 | 占比 | 用途 |
|------|------|------|
| 底仓 | 30% | 竞价弱转强 / 开盘确认后建 |
| 加仓 | 30% | 回踩均线不破 / 走强时加 |
| 子弹 | 40% | 应对炸板低吸 / 尾盘确认 |

### 5.2 单票限制

| 资金规模 | 持仓数 | 单票上限 |
|----------|--------|----------|
| ≤ 10 万 | 1-2 只 | ≤ 70% |
| 10-50 万 | 2-3 只 | ≤ 35% |
| 50 万+ | 2-4 只 | ≤ 25% |

### 5.3 总仓位 × 行情矩阵

| 市场状态 | 总仓位 | 单票上限 |
|----------|--------|----------|
| 放量上涨 + 主线明确 | ≤ 70% | ≤ 30% |
| 缩量震荡 + 板块轮动 | ≤ 40% | ≤ 20% |
| 缩量阴跌 + 无主线 | ≤ 20% | ≤ 10% |
| 急跌恐慌 | 30% 后手 | ≤ 15% |

### 5.4 连亏应对

| 连亏次数 | 应对 |
|----------|------|
| 2 笔 | 仓位降到 50% |
| 3 笔 | **当天停止交易，空仓 2 天**，重新从 50% 开始 |

> ⚠️ **亏损不补仓！** 亏损说明判断错了，补仓只会加大亏损。

## 六、市场环境匹配

### 6.1 大盘 × 个股矩阵

| 大盘趋势 | 个股状态 | 操作级别 | 策略 |
|----------|----------|----------|------|
| 上升趋势 | 放量突破 | **S-1 重仓出击** | 正常仓位 |
| 上升趋势 | 缩量回调 | A-2 回踩加仓 | 等确认信号 |
| 横盘震荡 | 放量突破 | A-1/A-3 中等仓位 | 降低仓位 |
| 下降趋势 | 放量突破 | 轻仓试错/放弃 | ≤ 20% 或空仓 |
| 下降趋势 | 其他 | **空仓** | 不参与 |

### 6.2 题材生命周期

| 阶段 | 特征 | 策略 |
|------|------|------|
| 萌芽期 | 首板零星出现 | 观察，首板试错 |
| 发酵期 | 连板出现，板块扩散 | **重仓出击**（最肥美阶段） |
| 高潮期 | 龙头加速，跟风补涨 | 持筹为主，去弱留强 |
| 退潮期 | 龙头断板，炸板潮 | **清仓，管住手** |
| 冰点期 | 涨停 ≤ 20，连板高度压到 2 板 | 做功课备选，等下一周期 |

## 七、V2 状态机

模拟持仓系统使用四状态机管理标的生命周期：

```
WATCH (观察池)
  │
  │ 收盘突破找顶线 + 量>MAVOL180×1.2
  ▼
READY (待买入)
  │
  │ 次日开盘买入（保护：非跌停/一字板）
  ▼
HOLDING (持仓中)
  │
  │ 涨停→继续持有 / 断板→卖出 / 满3天→卖出 / 亏损≥6%→止损
  ▼
FINISHED (已完成)
```

### 7.1 各状态说明

| 状态 | 含义 | 数据内容 |
|------|------|----------|
| `watch` | 距找顶线 ≤ 10%，等待突破 | code, name, close, top_line, dist_pct, vol_ratio, limit_count |
| `ready` | 今日触发买入信号，明日开盘买入 | + signal_date, buy_date, buy_price, score, break_pct, mode |
| `holding` | 当前持仓 | + had_zt (是否经历过涨停), current_price, unrealized_pnl_pct |
| `finished` | 已完成交易 | + sell_date, sell_price, net_ret, is_win, exit_reason |

### 8.1 按退出原因分层

| 退出原因 | 含义 |
|----------|------|
| 止损 -6% | 收盘跌到买入价 -6% 以下，硬止损 |
| 断板卖出 | 之前涨停过，今天不涨停了 |
| 持有 3 天到期 | 始终没涨停，第 3 天收盘卖出 |

### 8.2 按评分分层

| 分数段 | 含义 |
|--------|------|
| 90+ | 紧贴压力位 + 爆量涨停突破 → 最优信号 |
| 80-90 | 强突破信号 |
| 70-80 | 一般突破 |
| 60-70 | 弱突破 |
| <60 | 不符合 V2 资格过滤线（直接排除） |
